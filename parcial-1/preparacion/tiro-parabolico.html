Laboratorio de Tiro Parabólico

Un solo modelo, a = (ax, −g) constante, cubre el tiro horizontal, el oblicuo y el vertical. Mové los controles y mirá cómo cambian a la vez la trayectoria, las funciones x(t), y(t) y los números de las fórmulas.

Condiciones iniciales

0° es tiro horizontal, 90° tiro vertical.
La cátedra usa 9.8; varios parciales dicen "considere 10".
El viento del Ej. 15. Con 0 el eje x es un MRU puro.
Con altura 0 no se dibuja. Sirve para el arco, la muralla, la red.
